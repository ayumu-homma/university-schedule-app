# Project state

v1.0.0 is a GitHub portfolio/source release with a reproducible local Android demo. Public history begins at v1.0; historical development logs and private fixtures are not distributed. The mobile app is 1.0.0+1; shared_domain and admin retain their independent internal package version 0.1.0.

See [TESTING](TESTING.md) for current measured checks and historical evidence, [CHANGELOG](../CHANGELOG.md) for shipped source, and [ROADMAP](../ROADMAP.md) for UI/UX, evaluated 3D use, and real-user validation. Hosted services, physical/OEM Android, iOS, real providers and stores require separate acceptance. Public deployment workflow jobs are disabled.
