# Project state

v1.1.0 is the academic UI source release following immutable v1.0.0. Today, readable timetable selection, assignment/exam navigation and shared responsive/accessibility behavior are implemented; final acceptance is recorded in TESTING. Public history begins at v1.0; historical development logs and private fixtures are not distributed. The mobile app is 1.1.0+2; shared_domain and admin retain their independent internal package version 0.1.0.

See [TESTING](TESTING.md) for current measured checks and historical evidence, [CHANGELOG](../CHANGELOG.md) for shipped source, and [ROADMAP](../ROADMAP.md) for UI/UX, evaluated 3D use, and real-user validation. Hosted services, physical/OEM Android, iOS, real providers and stores require separate acceptance. Public deployment workflow jobs are disabled.

See [UX research](UX_RESEARCH_V1_1.md) and [design system](UX_DESIGN_SYSTEM.md) for source-grounded design and editable own wireframes. Official-document research and local synthetic tests are distinct from real-user usability acceptance. Optional spatial work follows after v1.1 acceptance; the 2D journey remains the default.
