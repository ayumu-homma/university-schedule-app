# 掲載画面の由来

`screenshots/v1.1/`は2026-10-12の専用Android API36 AVDによる比較です。beforeの3画像はv1.0.0、afterはv1.1候補（1.1.0+2）をlocal/demoで起動した画面です。v1.0からの更新前後に合成DB関連ファイルの内容が一致することを確認しました。後続の非同期フィードバックの文脈ガードは初期レイアウトを変更せず、別の回帰テストで検証します。画像を最終コード全体の受入証拠にはしていません。

架空の同じデモseedを使い、通常文字・明るいテーマ・1080×2400の画像を掲載します。撮影時の時計は日付や授業の「このあと」の判定に影響します。before/afterは同日の異なる時刻であり、表示内容の時刻差を性能改善の根拠にはしません。画像は自作アプリの実画面で、加工・生成による見せかけのUIではありません。

時間割・Today・課題は、v1.0.0候補を新しい専用Android API36エミュレーターでlocal/demoとして起動して2026-10-12に撮影しました。標準の架空デモseed（東京サンプル大学、A101/B203、アルゴリズム、Academic English）を使用します。実アカウント、本人の履修表、保持DBは使用しません。

資料選択と候補確認は2026-08-10のAndroid API36 local/demoの実画面を再利用します。fake extractorの合成候補で、実授業資料や実AIの出力ではありません。目視で実名・メール・学生番号・token・招待QR・ホストデスクトップがないことを確認し、PNGに識別用メタデータがないことを検査します。古い画面のため現在の全機能の証拠ではありません。

過去の履修画像に基づく時間割、履歴比較用の画像、デモ動画は収録しません。共有・グループの掲載素材は未提供です。画像の存在から実機、実配送、本番接続の受入を推測しません。
