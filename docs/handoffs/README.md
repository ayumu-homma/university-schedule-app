# Handoffs

Create a dated handoff here only when an execution limit or genuine external blocker interrupts unfinished work. A handoff must include the branch/commit, dirty files, active phase and acceptance criteria, commands/results, exact blocker, safe next command, and any unpushed changes.

Normal progress belongs in `PLANS.md` and `docs/PROJECT_STATE.md`; do not use handoffs as a substitute for keeping those current.
